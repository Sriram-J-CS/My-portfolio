## 🌌 Overview & Design Philosophy

This portfolio is built to reflect the intersection of defensive engineering and offensive security concepts. 
- **Cyber UI Aesthetic**: Built with a sleek HSL color scheme (creams, deep charcoal/blacks, and custom gradient gold tones).
- **Interactive Network Visualization**: Utilizing **Three.js** to render real-time interactive node-link network topologies on the background canvas that react dynamically to cursor movement/touch.
- **Performance-First Architecture**: Hand-crafted vanilla CSS and HTML with native scroll animations and intersection observers—zero bloat, fast load times, and responsive layout scaling.

## 🛠️ Key Highlight: CyberGuard Adaptive IDS

The focal point of the portfolio is **CyberGuard Adaptive IDS**, an AI-driven network intrusion detection and prevention system:
- **Traffic Capture**: Layer 2/3 sniffing via **Scapy** and **Npcap**.
- **ML Pipeline**: Stacked machine learning models including **XGBoost** (97.4% accuracy), **Random Forest** (98.7% accuracy), and **Isolation Forest** for zero-day anomaly detection.
- **Explaining verdicts**: Integrated **SHAP** values to make threat classifications transparent and explainable.
- **Active defense**: Host firewall rule injection to automatically block attacking IPs.
- **AI Analyst**: Claude API integration to summarize alerts and assist administrators with triage in plain language.
