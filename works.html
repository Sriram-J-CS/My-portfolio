CyberGuard Adaptive IDS

Featured · Capstone

An AI-driven network IDS and IPS that captures live traffic, extracts 62 flow-level metrics modeled on CICIDS2017, and classifies threats through a stacked pipeline — XGBoost (97.4% accuracy), Random Forest (98.7% accuracy), and an Isolation Forest for zero-day anomalies. Confirmed threats are auto-blocked at the OS firewall level. The platform ships with SHAP-based explainability, a live GeoIP threat map, a Claude API–powered alert triage assistant, and a role-separated real-time dashboard.

SKILLS I'VE GAINED

What this work actually taught me

Less a list of tools, more what building and breaking things repeatedly has trained into instinct.

Thinking in both directions

Building an IDS forces you to think like an attacker just to know what to detect. CTFs forced the reverse — I now default to asking "how would this get exploited" as part of any build, not as an afterthought.

Shipping ML beyond a notebook

Training a model is the easy 20%. Getting XGBoost, Random Forest, and Isolation Forest to run inference on live packet flows, in real time, behind a Flask API, taught me the operational half nobody puts in a tutorial.

Reading systems, not just code

Reverse engineering a packed binary or reconstructing Git history from a corrupted disk image is really the same skill: patiently reading a system's behavior when there's no documentation to fall back on.

Communicating risk clearly

Writing security assessment reports at Career Solutions taught me that a finding nobody can act on isn't a finding — it's noise. Clear, prioritized, actionable writing is as much a security skill as the technical work.

Engineering discipline

Debugging and performance work during my full-stack internship, plus proper Git workflows, built the baseline habits — testing before shipping, small reviewable commits — that carry into every project since.

Working without a safety net

CTFs and independent projects come with no instructor and no partial credit. That environment is where I got comfortable being stuck for hours and treating it as normal, not a sign something's wrong.
